Attendez, ça a l'air trop compliqué, faisons quelque chose de complètement différent. Ce que vous allez faire, et vous ne le ferez que, c'est que vous allez faire une liste de tous les files nécessaires pour que le Git Github Work et le Git Graph 2 fonctionnent. On fait cette liste et on va utiliser une simple ligne de commande pour les copier dans un autre ficheau. Ces fichiers seront juste là pour l'inspiration, pas pour le développement, donc ça ne m'importe pas si ils ne compilent pas.
